검색 방법

: 검색 조건을 만족하는 부품을 찾아서 리스트로 제공할 것. 리스트에는 부품명, 제조사, 스펙, 현재 주문 가능한 수량, datasheet 링크를 기입할 것.

검색 조건을 모두 만족하는 부품이 없을 경우, 검색 조건을 최대한 만족하는 부품으로 찾아줄 것

검색 조건

  1. PCB Library가 있을 것 : https://componentsearchengine.com 와 https://www.ultralibrarian.com 에서 검색이 가능해야하며, footprint와 3D 모델이 있어야 함

  2. 자재 주문이 가능할 것 : digikey와 mouser electronics에서 검색이 가능해야하며, 즉시 주문이 가능한 수량이 1000개가 넘어야 함

  3. 대체품이 있어야 함
