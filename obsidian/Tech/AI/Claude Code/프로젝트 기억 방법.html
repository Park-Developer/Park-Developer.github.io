Overview

각 Claude Code 세션은 새로운 컨텍스트 윈도우로 시작되며, 두 가지 메커니즘이 세션간에 지식을 전달한다.
  • CLAUDE.md 파일 : Claude에 지속적인 컨텍스트를 제공하기 위해 작성되는 지침
  • 자동 메모리 : 수정 및 선호도에 따라 Claude가 자신을 위해 작성하는 노트
  • claude의 동작을 제어하려면 CLAUDE.md 파일을 사용한다. 자동 메모리를 통해 Clause는 수동 작업 없이 수정 사항에서 학습할 수 있다.
