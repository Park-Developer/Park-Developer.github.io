Concept

: Hook은 Claude Code의 실행중에, 특정 이벤트가 발생했을 때 사용자가 정해 지정해놓은 Shell Command나 HTTP 요청 또는 프롬프트를 실행할 수 있는 기능이다.

Example

: 예를 들어 Claude Code를 통해서 파일을 수정했을때 자동으로 검사하도록 지시할 수 있다. => 물론 프롬프트를 통해서 지시할 수 도 있지만, 프롬프트는 가이드일뿐 Claude 모델이 지킬 수 도 안 지킬 수 도 있다. => 그래서 좀 더 명시적으로 어떤 이벤트가 발생했을 때 사용자가 특정 명령을 수행하도록 강제할 수 있다.
