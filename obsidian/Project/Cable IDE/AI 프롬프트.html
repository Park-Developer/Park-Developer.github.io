이 프로젝트는 cable 설계를 위한 pyqt5 기반 IDE(Integrated Development Environment)이고, 하기 내용을 바탕으로 python 코드와 프로젝트 설명에 대한 markdown 문서를 만들어줘.

  • 프로젝트창은 세개의 layout 또는 frame으로 이루어져 있으며,세개의 layout은 동시에 동작해야해.

  • 첫번째 layout은 바이브 코딩을 할 수 있는 사용자 입력을 받는 레이아웃이야. 사용자 입력을 받으면 사용자의 입력을 기반으로 mermaid 코드로 만들어야해. mermaid 코드는 케이블 도면처럼 보이도록 state diagram 형태로 그려져야하며, 커넥터와 커넥터를 연결하는 케이블이 나타나야해

  • 두번째 layout에 만들어진 mermaid 코드가 보이는 코드 편집기가 있어야해.

  • 세번째 layout에는 mermaid 코드를 diagram으로 보여주는 layout으로, 코드가 바뀌면 실시간으로 변경되어야해.
