ARM

Overview

: The Cortex-M4 processor is a low-power 32-bit RISC processor that features low gate count, low interrupt latency, and low-cost debug.

  • The Cortex-M4 with FPU is a processor with the same capability as the Cortex-M4 processor and includes floating-point arithmetic functionality.

Features

: Cortex-M4 processor includes * Processor Core * A Nested Vectored Interrupt Controller(NVIC) closely integrated with the processor core to achieve low latency interrupt processing. * Multiple high-performance bus interface * Low cost debug solution with the optional abaility * implement breakpoints and code patches * implement watchpoint, tracing, and system profiling * support printf style debugging * Bridge to a Trace Port Analyzer(TPA) * An optional Memory Protection(MPU) * A Floating Point Unit(FPU) *

Cortex-M4 Processor Components

  • Cortex-M4 Processor
  • Floating Point Unit (FPU)
  • Nested Vectored Interrupt Controller (NVIC)
  • Memory Protection Unit (MPU)
  • Cross Trigger Interface Unit
  • Debug and Trace
  • ETM interface
  • AHB Trace Macrocell interface
  • Bus interfaces
  • Debug port AHB-AP interface
