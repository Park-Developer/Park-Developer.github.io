Concept

: Arm 32-bit Cortex - M4 CPU with FPU, Adaptive Real-time accelerator(ART Accelerator)

System Architecture

  • STM32F4 Series
  • Arm 32-bit Cortex - M4 CPU
  • FPU
  • Adaptive Real time accelerator
  • Embedded flash memory
  • CRC(Cyclic Redundancy Check) Calculation Unit
  • Embedded SRAM
  • Multi-AHB(Advanced High-Performance) bus matrix
  • DMA(Direct Memory Access) Controller

Memory Organization

: Program memory, data memory, registers and I/O ports are organized within the same linear 4 Gbyte address space.

-> The bytes are coded in memory in little endian format.

  • Embedded SRAM
  • Embedded Flash memory
  • Bit banding
  • Boot Configuration
  • Embedded bootloader
  • Physical Remap in STM32F42xxx and STM32F43xxx
