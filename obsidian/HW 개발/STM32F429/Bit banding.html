Overview

: The Cortex-M4 with FPU memory map includes two bit-band regions. These regions map each word in an alias region of memory to a bit in a bit-band region memory.

  • Writing to a word in an alias region has the same effect as a read-modify-write operation on the targeted bit in the bit-band region.
  • In the STM32F4xx devices, both the peripheral registers and the SRAM are mapped to a bit-band region, so that single bit-band write and read operation are allowed.
  • The opertions are only available for Cortex-M4 with FPU accesses, and not from other bus masters(e.g., DMA)
