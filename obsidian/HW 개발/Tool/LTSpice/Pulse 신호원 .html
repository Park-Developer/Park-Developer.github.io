신호원 설정

- Vinitial : Voff로 시작할때의 전압과 pulse가 off일 때의 전압을 설정 - Von : pulse가 on일때의 전압 - Tdelay : time delay before pulse starts - Trise : pulse가 off에서 on전압으로 될 때까지의 걸리는 시간 => 0으로 설정하면 default값으로 0으로는 되지 않는다. 0으로 설정하고 싶은 경우에는 0에 가까운 값으로 설정한다. - Ton : Pulse의 On 상태의 시간이다. - Tperiod : Pulse의 주기를 나타내는 시간 - Ncycles : Pulse의 cycle 수를 설정한다. 설정하지 않거나 0을 설정하면 pulse는 계속 발생한다.
