기존 Project Import

  1. File -> Imoort -> Select : General/Existing Projects into workspace.

  2. 설정값 확인

  3. Project explorer에 import한 프로젝트들이 나옴

  4. Import 프로젝트 실행시켜보기(CORTEX_12_PRINTF_f429)

    • 4-1) 실행할 프로젝트 선택 => 다른 프로젝트들은 모드 close하기 (close unrelated project 선택)

      4-2) Project Build

  5. Project 동작 확인

    • 5-1) 디버그 모드 진입 및 실행

    • 5-2) 출력 확인
