Overview

: An LDO is nothing more than a three terminal linear system providing closed-loop control. The solution is easy to implement, requiring only the device itself and an input and output capacitor.

LDO Operation

: An LDO can be thought fo as a variable resistor.

=> LDO is built from four main elements : (1) pass transistor, (2) bandgap reference, (3) operational amplifier, (4) feedback resistor.

Designing with an LDO

  1. Output Voltage : Many LDOs are supplied in standard fixed output voltage. However, some LDOs are offered with an adjustable output voltage. This requires the designer to use an external feed-back resistor divier.

  2. Dropout Voltage : The sum of the output voltage and the typical dropout voltage must be less than the minimum input voltage. If the sum is greater, the LDO will not be able to regulate the output at minimum input voltages.

  3. Output Capacitor : A very important specification that should not be over looked is the requirments that some LDOs place on the output capacitor.

    Certain LDOs require the output capacitor to be either tantalum or aluminum electrolytic to produce a stable system. These capacitors have a large ESR(Equivalent Series Resistance)

LDO Parameter

  • $I_{GND}$ : the current used by the LDO to perform the regulating operation and is often referred to as the quiescent current($I_q$) for no load conditions.

  • Efficiency : When the LDO output current is much greater than the device quiescent current, the system efficiency is found by dividing the output voltage by the input voltage.

    System line and load step performance is greatly improved on LDOs that have higher Iq. Since the Iq is used by the LDO to preform the regulating operation, it can respond quicker to a sudden change in load requirements or line voltage.
