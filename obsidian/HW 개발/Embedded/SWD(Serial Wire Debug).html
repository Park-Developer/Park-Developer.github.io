Overview

SWD는 ARM 코어 기반 MCU들에서 주료 활용되는 디버깅 통신 방식이다.

SWD는 JTAG과 달리, 클럭과 단일 양방향 데이터핀만 있어도, 기존의 5핀 JTAG 디버그 인터페이스를 대체할 수 있다.

Pin map

  • SWDIO(Serial Wire Debug I/O) : 양방향핀이며, 디버깅 명령, 데이터 및 응답을 전송하는데 사용됨
  • SWCLK(Serial Wire Clock) : 클럭 신호 전송핀으로, 디버깅 장치와 CMU간의 동기화 역할을 한다.
  • Reset : MCU를 reset하는데 사용된다.
