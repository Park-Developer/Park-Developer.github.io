Overview

: NAND Flash 메모리와 Flash 메모리 컨트롤러가 결합되어 있는 메모리 카드이며, 단순 일체형 보드와는 다르다.

Concept

: NAND Flash 메모리는 여러 구역에서 지우고 쓸 수 있고 EEPROM에 비해 저렴하다. NAND Flash 메모리는 단지 저장 장치이므로 호스트 측 컨트롤러에서만 데이터 전송을 조작할 수 있다. => NAND Flash 메모리만 가지고는 write 할 수 없으므로 컨트롤러를 통해 write를 수행할 수 있게 만든 보드가 eMMC이다. => eMMC는 read와 write가 가능한 메모리이다. => NAND 플래시를 호스트에 직접 연결하는 것과 비교할 때 호스트측 소프트웨어의 복잡성을 줄일 수 있다.
