Overview

The proprietary Adaptive real-time(ART) memory accelerator is optimized for STM32 industry-standard Arm Cortex M4 with FPU.

-> It balances the inherent performance advantage of the Arm Cortex-M4 with FPU over flash memory at higher frequencies.

  • To release the processor full 225 DMIPS performance at this frequency, the accelerator implements an instruction prefetch queue and branch cache, which increases program execution speed from the 128-bit flash memory.

  • The performance acieved thanks to the ART Accelerator is equivalent to 0 wait state program execution from the flash memory at a CPU frequency up to 180 MHz.
