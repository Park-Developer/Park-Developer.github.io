Overview

: The processor contains an Advanced High-performance Bus access Port(AHB-AP) interface for debug accesses. An external Debug Port(DP) component accesses this interface.

The Cortex-M4 system support three possible DP implementations:

  • Serial Wire JTAGH Debug Port(SWJ-DP) : The SWJ-DP is a standard CoreSight debug port that combines JTAG-DP and Serial Wire Debug Port(SW-DP)
  • SW-DP : This provides a two-pin interface to the AHB-AP port
  • No DP present : If no debug functionality is present within the processor, a DP is not required
