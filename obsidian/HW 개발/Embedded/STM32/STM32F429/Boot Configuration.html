Overview

:Due to its fixed memory map, the code area starts from address 0x0000 0000(accessed through the ICode/DCode buses) while the data area(SRAM) starts from address 0x2000 0000(accessed through the system bus)

  • The Cortex®-M4 with FPU CPU always fetches the reset vector on the ICode bus, which implies to have the boot space available only in the code area (typically, flash memory).
  • STM32F4xx microcontrollers implement a special mechanism to be able to boot from other memories (like the internal SRAM).
