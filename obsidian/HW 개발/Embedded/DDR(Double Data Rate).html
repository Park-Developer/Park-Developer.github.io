Concept

DDR은 Double Data Rate의 약자로, DRAM의 한 종류이다.

DRAM은 휘발성 메모리이기 때문에 정상적인 동작을 위해서는 지속적으로 데이터를 Refresh하는 특성이 있다. 리프레시 작업은 일정한 주기로 수행되며, 이를 위해 클럭신호가 사용된다.

DDR vs SDR

기존의 SDR(Single Data Rate) DRAM은 클럭이 높아질 때만 데이터를 전송하는 방식이었으며, 하나의 클럭사이클에서 한 번만 데이터를 전송할 수 있다.

하지만 DDR(Double Data Rate) DRAM은 상승 엣지뿐만 아니라 하강 엣지에서도 데이터를 전송하는 방식으로 동작한다. => 하나의 클럭사이클에서 두 번 데이터를 전송하므로, 같은 클럭 속도에서 SDR 대비 2배 빠른 데이터 전송 속도를 제공한다.
