Concept

ELF(Executableand Linkable Format)은 리눅스, 유닉스 등에서 사용되는 실행 파일, 공유 라이브러리 등의 파일 형식이다.
  • ELF 형식은 프로그램의 코드, 데이터, 심볼, 리눅스 커널과의 인터페이스 등을 담고있다.
  • ELF 파일의 내부 정보를 분석하면, 프로그램의 구조, 코드 정보, 프로그램의 실행 과정 등을 파악할 수 있습니다
  • 실행 파일의 로딩, 링킹, 디버깅, 성능 프로파일링 등에 활용된다.

ELF 명령어

ELF 파일을 분석하기 위해 사용할 수 있는 명령어는 다양하지만, 주로 사용되는 명령어는 다음과 같습니다:
  • readelf: ELF 파일의 헤더 및 섹션, 심볼 등의 정보를 출력합니다.
  • objdump: ELF 파일의 어셈블리어 코드를 출력합니다.
  • nm: ELF 파일의 심볼 정보를 출력합니다.
  • strace: ELF 파일이 실행될 때 시스템 콜 호출 정보를 출력합니다

ELF 파일 구조

ELF 파일은 보통 ELF Header + Program Header Table + Section Header Table로 구성된다.
