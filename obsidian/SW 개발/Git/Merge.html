Merge Command

: Incorporates changes from the named commits(since the time their histories diverged from the current branch) ~={red}into the current branch=~

GIT CLI Merge 예시

: main과 coupon 브랜치에서 작업하고 있는데, coupon 브랜치의 내용을 main에 합치고 싶은 경우

  1. main 브랜치고 checkout하고
  2. coupon 브랜치를 합침

=> 이러면 coupon 브랜치의 코드들이 main 브랜치에 합쳐진다.

  1. 충돌 해결

Source Tree Merge 예시

: Branch에서 Master로 병합하는 경우 => Master 브랜치에 checkout 후 branch 병합
