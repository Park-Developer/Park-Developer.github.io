Git Rebase

: Transplant a series of commits onto a different starting point.

사용 하는 이유

: 브랜치가 너무 많을 경우, 3-way merger만 진행하면 git log가 너무 복잡해 보일 수 있음.

git log를 간단하게 하기 위해서는 fastforward를 하는게 좋은데, 충돌이 있는 경우 fastforward가 불가능함

이를 해결하기 위해 rebase를 한 후 fastforward를 진행하여 git log 단순화

3-Way Merge VS Rebase & Merge

: 일반 merge는 합쳐지는 대상이 되는 브랜치(master)에 이동해서 merge를 진행하지만, rebase는 새로운 브랜치로 이동해서 rebase 진행. rebase 진행 후에 다시 master로 이동해서 merge 진행
